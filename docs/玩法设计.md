# 玩法设计 · Godot 原型

## 核心体验

玩家移动和旋转下落的四连方，让同色的「整块」连接，创造消除与连锁。暂定中文名「色块连落」，英文名 Chroma Drop；名称尚未定稿。

## 术语

| 术语 | 定义 |
| --- | --- |
| 格子 | 棋盘的最小占位单位，不单独参与匹配计数 |
| 方块 | 一个完整的 I、O、T、L、J、S 或 Z 四连方，由四个格子构成 |
| 颜色 | 整个方块的属性；一个方块内所有格子同色 |
| 相邻 | 两个不同方块至少有一对格子共用一条边；角接触不算 |
| 匹配组 | 三个及以上同色方块通过相邻关系连成的连通组 |
| 连锁 | 一次落地结算中，消除后的重力再次产生消除 |

## 已确认方向

1. 同色三消数的是三个方块，不是三个格子。
2. 匹配不要求排成直线；通过边接触形成连通组即可。
3. 消除后整块下落，不拆散为独立格子。
4. 讨论使用英文，文档使用中文。
5. 使用 Godot + C#；界面只保留棋盘与必要 HUD，不使用网页式标题或装饰面板。

## 原型默认值（供试玩验证）

- 棋盘为 10 列 × 18 行。
- 使用七种标准四连方，七袋随机抽取；四种颜色独立等概率分配。
- 展示接下来三个方块，显示当前形状的落点投影。
- 完整横行不额外消除，避免首次实验混入第二套规则。
- 没有交换方块、暂存、道具或旋转方向选择。
- 方块落地后有 380 毫秒锁定延迟，硬降立即锁定。
- 旋转采用简单边界修正，不是标准 SRS 旋转系统。
- 每锁定 15 块，下落间隔减少 70 毫秒；从 850 毫秒起，最低 180 毫秒。
- 默认进入三关挑战组的第一关「蓄势连消」，侧栏可直接选择其他挑战、学习关卡或遵循以上默认值的自由模式。失去窗口焦点时自动暂停。解谜模式 F2 查看提示，自由模式 F2 载入固定匹配示例。

## 结算流程

1. 当前方块锁定并成为静态方块。
2. 找出所有符合条件的同色连通组，同时清除其中的完整方块。
3. 若无匹配，直接生成下一块；正常落地不主动重排已经堆积的方块。
4. 有消除时先播放短暂闪烁，再让所有失去支撑的方块按整块下落。
5. 任一格接触底部或受到其他已支撑方块阻挡，即可支撑整个形状；允许悬挑。
6. 完全稳定后重新检测匹配，若有则连锁继续；没有则生成下一块。
7. 出生位置被占据时游戏结束。

## 计分

每波分数由五部分相加：

```text
1000
+ 高度行数 × 100
+ round_to_100(3000 × 消除方块数 ÷ (匹配区域宽度 + 匹配区域高度))
+ 1000 × (2^min(消除方块数 - 3, 3) - 1)
+ (连锁层数 - 1) × 5000
```

- 高度行数从棋盘底部量到匹配组的最低格；只有整组都处在高处才获得完整高度奖励，避免竖直长块以一个高格刷分。
- 匹配区域是本波所有消除方块的格子包围盒。宽高之和越小，紧凑奖励越高；该项四舍五入到最接近的 100 分。
- 多块消除从三个方块的 0 分开始，四 / 五 / 六个方块分别奖励 1,000 / 3,000 / 7,000 分；六个以上保持 7,000 分，防止指数增长破坏长期最高分。
- 首波连锁层数为 1，不加连锁奖励；第二波加 5,000，第三波加 10,000，依此类推。
- 多个独立匹配组在同一波消除时，共用包围盒、方块数与连锁层数。

示例：底部横排三个 O 的包围盒为 6 × 2，得到 `1000 + 1100 = 2100` 分；整体提高六行后得到 2,700 分。两波相同的底部三消得到 `2100 + 7100 = 9200` 分。紧凑的六块同波消除示例得到 9,800 分。

## 可读性原则

同色方块贴在一起时仍必须能分清块数。每块用完整外轮廓分隔，内部格子没有同样粗的分割线。颜色辅以圆点、方框、十字、斜线四种标记，减少只靠颜色识别的压力。

## 首次试玩问题

1. 玩家能否准确判断「两块」和「三块」，尤其是同色复杂形状接触时？
2. 四种颜色是否造成等待过长或随机性过强？
3. 刚体重力形成悬挑时，结果是否容易预测？
4. 不消除完整横行是否让堆叠容易进入无法挽回的状态？
5. 连锁是否值得提前规划，还是基本来自偶然？

先根据这些问题迭代，再决定是否加入横行消除、暂存或特殊方块。
