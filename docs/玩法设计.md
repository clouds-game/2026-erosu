# 中心方环 · Game0 规则

## 核心循环

一手七种标准四连方 → 选择块和顶部入口 → 与核心结构连接 → 完整方环消除 → 外层连通块向中心移动 → 每四次成功投放旋转棋盘 → 清空 Hand 后刷新。

Hand 的顺序自由由 75 秒绿条约束；超时后红条表示 Lock 状态，白框按从左到右的剩余顺序移动。猫猫是独立资源，可在 Lock 时插入使用，并从四侧进入。

## 棋盘与投放

- 棋盘为 13×13，中心 `(6,6)` 为永久白色核心。
- 每 Hand 包含 `I/J/L/O/S/T/Z` 各一块，顺序洗牌。手中块可旋转，普通块只从顶部进入。
- 投放沿入口方向逐格移动。若下一步将与核心或已有格重叠，则停在当前位置；此时必须完整位于棋盘内且与核心或有效结构边相邻。穿过远端边界的块返回原槽，不计成功投放，Hand 时间照常流逝。
- 拖动时不显示落点预览；松手后播放快速下落动画。没有连到核心结构的普通块穿过棋盘底部，返回原 Hand 槽位。猫猫从四边任选入口，仍为四格 Tetromino。
- 所有成功放置且未被消除的格子都保有“有效结构”身份。清环后失去到核心的直接路径，也不因此失效。

## 环与收缩

环半径按到中心的切比雪夫距离计算，`r=1..6` 分别包含 `8r` 个格子。某半径的全部格子占满即完成方环，与颜色无关。

一次投放先同时检测所有直接完成的环并清除对应格子。清除可以切断一个原来的 Tetromino；余下格子重新按四向边接触组成连通块。每个连通块作为整体逐步向中心平移：每一步只能走到空位，且格子到中心的曼哈顿距离之和必须下降。优先选择下降最多的方向，平局按上、右、下、左处理；内侧块先处理。无法移动的连通块原位悬浮，仍然可连接。收缩形成新环时继续结算，直到稳定。

每波完成 `k` 环得 `50k(k+1)` 分。一次投放的**首波**直接完成至少两环时，奖励随机形状猫猫一块；每次投放最多奖励一块，库存满四块时忽略奖励。单环没有猫猫。

## 旋转、时间与失败

- 每四次成功投放，包括猫猫，结算结束后棋盘绕核心转 90°。原型固定顺时针、逆时针交替，并提前显示下一方向和剩余次数。
- 一手共 75 秒，仅在玩家可操作时减少；暂停与结算动画不计时。绿条归零后变为满红条，剩余 Hand 从左到右逐个锁定。猫猫不消耗 Hand、不解除 Lock。
- 绿色阶段任意剩余普通块可用；红色阶段仅当前白框普通块可用。当当前允许的普通块没有合法落点时，库存中可投放的猫猫仍提供最后机会。两者都无合法落点时 Game Over。

## 需要试玩检验

75 秒和四次旋转是首版参数。重点记录：首次完成方环所需放置数、穿底频率、每百次投放的双环次数、猫猫使用率、Lock 死亡率，以及原位悬浮结构是否让局面难以预测。
