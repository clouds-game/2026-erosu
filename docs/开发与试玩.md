# 开发与试玩 · Godot + C#

## 技术方向

根据用户最新决定，主项目改为 Godot + C#。根目录可直接作为 Godot 项目导入；早期 TypeScript 网页实验归档至 `archive/web-prototype/`。归档与测试目录包含 `.gdignore`，避免引擎导入无关文件，C# 项目也排除了这两个目录的源代码。

当前目标是本地桌面试玩。基准视口为 720 × 804：左侧 10 × 18 棋盘，右侧仅保留分数、最高分、后续块、统计、按键提示和操作按钮。没有品牌栏、大标题、宣传卡片或网页装饰。初始窗口会按显示器缩放比例放大，并限制在可用屏幕范围内。

## 模块边界

- `Core/Piece.cs`：格子、完整方块和七种形状。
- `Core/PieceBag.cs`：七袋随机形状、四色随机和唯一身份。
- `Core/Board.cs`：占位、连通组匹配、整块重力。
- `Core/GameSession.cs`：下落、锁定、消除、重力、连锁、出生和结束状态。
- `Game/GameController.cs`：Godot 输入、长按重复、失焦暂停、声音和本地持久化。
- `Game/BoardView.cs`、`PiecePainter.cs`、`NextView.cs`：棋盘、形状与预览绘制。
- `Game/GameHud.cs`：必要 HUD 和按钮。
- `Game/GameAudio.cs`：简易合成音效。

规则与计时可脱离 Godot 测试。Godot 只负责驱动状态机与表现。消除期间不接受新块输入；暂停会冻结当前消除和重力阶段；失焦自动暂停。


## 手动试玩清单

1. 打开即进入棋盘，确认没有网页式外围装饰。
2. F2 载入示例，Space 落地，确认三块消除与 300 分。
3. 验证左右移动、长按、旋转、软降、硬降及落点预览。
4. 消除承重块，检查完整形状下落及连锁计分。
5. 暂停 / 恢复与切换窗口，确认时间和输入冻结。
6. 堆至出生区，确认结束和重开。
7. 缩放窗口，确认棋盘与必要信息可读。
8. 开关音效；重新启动确认最高分与声音设置保留。

## 版本管理约定

由助手管理本项目的 Git 提交。完成独立、可验证的改动后，执行相关检查并创建清晰的提交；提交包含代码、必要资源与对应中文文档，不包含构建产物、依赖目录或本机缓存。

## 后续讨论

继续优先验证块数是否容易辨认、颜色随机性是否合理、悬挑重力是否容易预测，以及是否需要满行消除。确认后再扩展精修特效、引导、难度与发行打包。当前没有联网或托管部署。
