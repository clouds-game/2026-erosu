# 界面国际化

桌面版（Godot C#）与网页版（.NET WebAssembly）支持 English、简体中文、日本語。右侧底部切换语言，立即生效，不重置分数、棋盘或当前消除动画。桌面按钮依次循环三种语言；网页版使用下拉列表，聚焦列表时暂停游戏，避免方向键同时控制方块。

首次运行读取系统 / 浏览器语言；`zh`、`zh-*`、`zh_*` 与 `cn` 统一使用简体中文，`ja-*` 使用日语，其余语言回退英文。内部使用标准代码 `en`、`zh-CN`、`ja`。目前不提供繁体中文翻译。

桌面偏好保存到 `user://progress.cfg` 的 `settings.language`，与最高分、音效设置一起保留；网页保存到 localStorage 的 `chroma_language`。浏览器禁止存储时仍可在当前会话切换语言。

## 文案与维护

- `Localization/strings.json` 是唯一翻译源，包括 HUD、暂停 / 结束界面、教程与消除提示、按钮、操作说明、网页无障碍标签、加载 / 错误提示。
- `Localization/UiText.cs` 提供语言解析、英文回退和占位符格式化，两个客户端嵌入同一份资源。
- 网页启动阶段从发布目录的 `locales.json` 读取相同文案；正式游戏界面等待偏好加载完成再显示，避免先闪现英文。
- 临时通知保存文案键与参数，切换语言后可立即翻译已有通知。
- 数字统一使用逗号千位分隔；快捷键保持原键位，产品名 Chroma Drop 保持不变。
- 添加文案时三种语言必须具有相同键和 `{0}` 等占位符。测试会检查完整性、占位符及语言回退。

## 字体

随包提供 Noto Sans CJK Sans2.004 的简体中文 / 日文字形子集，以免依赖玩家系统的语言字体。中文使用 SC 字形，日语使用 JP 字形；网页按 `html.lang` 选择字体。子集约 80 KB / 份，完整许可证见 `Assets/Fonts/OFL.txt`，来源与再生成方式见 `Assets/Fonts/README.md`。

修改翻译增加字符后，重新生成字体子集并检查缺字。原生侧栏已为 CJK 字体行高预留空间，棋盘通知根据宽度缩小字号；网页侧栏允许文案换行。

## 验证

- `dotnet run --project Tests/ChromaDrop.Tests.csproj -c Release`：20 项规则与国际化测试。
- `npm run build --prefix Web`、两个 C# 项目构建及 Web 发布。
- Codex 内置浏览器：切换三种语言，检查暂停、演示、无障碍标签、刷新后的偏好保存。
- Godot 原生窗口：检查中文 / 日文字形、侧栏间距和保存后的语言恢复。
- Pages 部署检查新增翻译 JSON 和两份字体资源的可访问性。
