# 关卡设计 · 第一章草案

状态：前三关归入可选「学习」分组，作为教学内容保留；默认玩法为三关独立挑战组，详见《挑战关卡》。使用固定棋盘、固定序列、无自动下落的解谜规则；保留自由模式。下文原第 4–6 关仅保留为后续学习内容草案，不占用当前稳定关卡 ID。

## 设计目标

先让玩家学会数「完整方块」、识别边连接，再引入搭桥与整块重力，最后要求主动制造连锁。难度来自棋盘关系与落点选择，而不是先提高下落速度。

自由模式 HUD 中的 Level 表示速度等级。解谜模式改为关卡目标与剩余方块；侧栏选择器标示关卡编号和名称。

## 前三关的棋盘草案

棋盘仍为 10 列 × 18 行；坐标从左上角 `(0, 0)` 起。每条记录表示一个完整方块，以当前 `Piece.Create` 的默认朝向定义。红色为颜色 0，绿色为颜色 1；颜色名称还应配合现有图案标记呈现。

### 01 · 第三个伙伴

- 初始：红 O `(0, 16)`，红 O `(2, 16)`。
- 待落序列：红 O。
- 参考操作：移动至左边界 x=4，直接落下；落在 `(4, 16)`，三块消除。
- 目标：累计消除至少 3 个方块。
- 提示：已经接触的两个红色 O 虽然包含八个格子，也只算两个方块。

### 02 · 拐角不是连接

- 初始：红 O `(0, 16)`，绿 O `(2, 16)`，红 O `(2, 14)`。
- 待落序列：红 O。
- 两个红块初始只有角接触；上方红块由绿块支撑。
- 参考操作：移动至 x=0，直接落下；落在 `(0, 14)`，分别与两个红块通过边连接并消除。
- 目标：累计消除至少 3 个方块；绿块留在棋盘上也算成功。
- 提示：不是排成直线，而是通过边连成一组。

### 03 · 一座桥

- 初始：红 O `(0, 16)`，红 O `(6, 16)`。
- 待落序列：红 I（默认水平朝向）。
- 参考操作：移动至 x=2，直接落下；I 落在 y=17，连接左右两个 O。
- 目标：清空所有初始红块与本关待落红块。
- 提示：长条本身只有一个方块；它可以把两个分离的组连起来。

## 草案验证记录

已直接调用当前 C# `Board` / `Piece` 检查前三关：初始布局合法、稳定且不存在匹配；参考硬降落点分别为 `(4, 16)`、`(0, 14)`、`(2, 17)`；均消除三个完整方块，剩余方块数分别为 0、1、0。现已接入有限序列、胜负目标与真实输入回放测试，浏览器也完成逐关试玩。未穷举替代解法。

## 当前关卡规则

- 使用固定初始棋盘与有限待落序列；相同关卡每次重试一致，不能在序列结束后补入随机块。
- 首章不自动下落，玩家移动、旋转或主动落下后才推进；消除与重力动画仍按现有节奏播放。后续再讨论是否引入计时挑战。
- 成功与失败均在当前消除、重力和连锁完全结束后判断。最后一个方块触发连锁时，不能因序列已空而提前判负。
- 待落序列耗尽仍未达标，或出生位置被阻挡且目标未完成，则失败；立即提供重试。
- 每关一个主要目标，不在首章同时叠加时间、分数、特定颜色、步数和清空率。
- 第一版只记录通关，不加三星评级、体力、付费提示或分支地图。
- F2 / 提示按钮显示本关提示，持续 12 秒；暂停时请求提示会恢复到无自动下落的思考状态。后续可扩展为两级提示。
- 中文设计文档保持唯一说明入口；关卡名称、目标、提示与过关 / 失败文案均进入现有 en / zh-CN / ja 翻译体系。

## 实现前的验收要求

1. 初始棋盘无重叠、越界、意外三消或无支撑悬空块。
2. 每关至少一条通过真实移动、旋转、硬降操作可达到的解；只检查最终棋盘合法性不够。
3. 检查其他解法是否绕过本关教学点；允许合理多解，不靠隐藏条件强迫参考解。
4. 最后一步成功、连锁后成功、序列耗尽失败、出生阻挡失败、暂停与重试都有明确行为。
5. Godot 与网页使用同一关卡数据和目标判断，布局继续保持单屏可见。

## 试玩与存档

默认进入挑战；模式 / 关卡选择器的「学习」分组可选择这三关。所有三关均可直接选择，无需按顺序解锁。名称后的 `*` 表示曾经通关；网页同时显示「已完成」。

- 第 1 关：默认落点即可，按 Space / 直接落下。
- 第 2 关：向左移动 4 次，再直接落下。
- 第 3 关：向左移动 1 次，再直接落下。
- 失败后重试；通关后按钮或 Enter 进入下一关；学习第 3 关后显示学习完成并可进入挑战。
- R 总是重试当前关卡；切换关卡与自由模式会重新开始相应对局。
- 只保存通关记录，不保存未完成的棋盘。Godot 使用 `progress.completed_levels`，网页使用 localStorage 的 `chroma_completed`；各端独立保存。
- 解谜得分不会写入自由模式最高分，避免固定关卡刷分混入记录。
