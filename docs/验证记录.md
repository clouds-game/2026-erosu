- 画面仅有棋盘、必要 HUD 和按钮，没有网页式标题或宣传装饰。

音效合成和播放代码已通过编译及引擎启动，但未对音色或音量进行听感验收。本段记录初版原生窗口验收；桌面导出与网页验证见下文。触屏实机与音效听感仍未验收。
