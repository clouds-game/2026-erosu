# 自由模式选项

进入自由模式后，先选择颜色配置和玩法选项，再按「开始」。网页和 Godot 桌面使用相同配置。

## 选择矩阵

颜色配置三选一：

| 配置 | 颜色权重（红、绿、黄、紫、粉、青、金） |
| --- | --- |
| 五色 | 10、9、8、7、6、0、0 |
| 六色 · 含金色 | 25、22、19、17、14、0、3 |
| 七色 · 含金色 | 22、20、18、16、14、7、3 |

玩法选项可以独立组合：随机固定色块、填充闭合空白。选中项用边框标识；键盘焦点另有边框。
默认七色配置，两项玩法关闭。颜色权重及金色奖励沿用现有规则，不在此面板调整。

按「开始」创建新自由局。取消或 Escape 放弃未应用的修改，返回原来的对局。
重新开始沿用当前配置；再次进入选项面板时显示当前自由局配置。配置仅保留在本次运行中。
谜题不使用自由模式选项。最高分按三种颜色配置与两项规则的十二种组合分别保存，保留原七色配置的历史记录键。

## 启动预选

网页 `?mode=free` 打开选项面板。可用 `color_profile=classic`、`rare_six` 或 `rare_seven` 预选颜色，
并用 `anchored_blocks=true`、`enclosed_fill=true` 预选规则，例如：

```text
?mode=free&color_profile=rare_six&anchored_blocks=true&enclosed_fill=true
```

桌面：

```sh
./tools/play -- --free-play --color-profile=rare_six --anchored-blocks --enclosed-fill
```

这些参数打开预选面板，仍需按「开始」。无界面 JSON 引擎的启动协议保持原有行为，不弹出面板。
界面支持英文、简体中文和日文。
