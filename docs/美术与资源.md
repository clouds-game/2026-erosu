# 美术与资源 · Godot 原型

## 当前方向

优先呈现游戏本身：深色棋盘、四种清晰的块色、整块外轮廓，以及分数和后续块等必要信息。去掉网页实验中的大标题、品牌、介绍卡片、页脚和宣传装饰。不制作独立启动宣传页，游戏打开即进入棋盘。

| 棋盘 | `#1b212c` |
| 珊瑚红 | `#ff8278` |
| 薄荷绿 | `#8ee2c4` |
| 奶油黄 | `#f6ce71` |
| 浅紫 | `#aaa2f7` |

同色相邻方块必须保留外轮廓，避免玩家误将几个方块看成一个。每格的圆点、方框、十字或斜线辅助识别颜色，但匹配计数仍以整块为单位。

## 后续流程

1. 试玩确认轮廓、密度和颜色数量。
2. 根据实际反馈调整绘制效果，避免加入妨碍辨识的装饰。
3. 确定需要的精修资源，再制作和替换临时声音或特效。
4. 在实际窗口尺寸下验证清晰度、缩放和反馈时序。

目前不需要宣传插画、角色或网页美术资源；之后新增素材必须服务于游戏体验。
