Godot + C# 桌面版本，与 .NET WebAssembly 网页版本共享核心规则。

- Windows：下载 `chroma-drop-windows-x64.zip`，完整解压后运行 `ChromaDrop.exe`。请保留旁边的资源和运行时文件。
- macOS：下载 `chroma-drop-macos-universal.zip`，解压后运行 `ChromaDrop.app`；同时支持 Apple Silicon 与 Intel。
- 不需要额外安装 Godot 或 .NET。
- 包含 SHA-256 校验文件。
- 当前 Windows 未使用商业代码签名，macOS 使用临时签名、尚未经过 Apple 公证；系统可能提示无法验证开发者。正式公开发行前应配置正式签名与公证。

操作：方向键移动与旋转，Space 落地，P 暂停，R 重开，F2 匹配示例。
