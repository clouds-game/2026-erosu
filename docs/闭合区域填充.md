# 闭合空白区域填充

自由模式增加独立的可选规则，默认关闭，可与固定色块机制组合。已有谜题与三消演示不添加此规则。

## 闭合定义

从棋盘顶行的所有空格出发，只沿上下左右空格扩展。无法从这些入口到达的空格为闭合区域。
左右墙和地板可以成为边界；斜角接触不算通路。多个分离区域一起检测，但只填充本轮新变为闭合的空格。
整行封顶会使其下方全部空白成为闭合区域，因此一次可能填入很多格。

## 结算顺序

1. 当前普通块锁定，先完成已有匹配和重力连锁。
2. 若启用固定色块，放置已到预告队首的固定单格事件。
3. 检测新闭合空格，逐格按当前颜色概率独立抽取颜色；同一次填充内，边相邻的同色格子合并为一个普通块。
4. 填充后按普通三消规则继续消除与重力，最后生成下一普通块。

每个锁定块最多填充一次；填充引起的消除不会在同一轮再填充，避免填充—消除循环。
旧闭合区域不会在后续轮次反复填充。填充块被消除后，若原空白仍闭合，也不再次填充。
区域通过上下左右空格重新连通顶行后解除记录；之后再次闭合可以重新填充。开局已有闭合空白视为旧区域。

填充格子不覆盖现有块。同一次填充内的同色连通格子共享一个 ID，作为一个刚性块参与重力、匹配和计分。
三消按块数计算，三个同色填充格若合为一个块，不会独立触发三消。对角接触不合并，旧块以及不同填充批次不合并。
填充块受普通重力影响，通过三消移除；支撑被清除后整块下落。
“不同颜色”指逐格独立随机，不保证相邻格一定异色，也不保证每个区域包含全部颜色。
新格子可能直接参与匹配并产生普通分数、稀有色奖励和连锁，局部可能成为收益而非惩罚。
最高分按普通、固定色块、闭合填充、两者组合分别保存，避免混合比较。

## 启动

桌面：

```sh
./tools/play -- --enclosed-fill
./tools/play -- --enclosed-fill --anchored-blocks
```

网页：`?enclosed_fill=true`；组合使用 `?enclosed_fill=true&anchored_blocks=true`。
省略参数或设为 false 即关闭；启动参数打开自由模式选项面板并预选规则，按「开始」后应用。

无界面引擎：

```json
{"command":"start","mode":"endless","seed":42,"enclosed_fill":true}
{"command":"start","mode":"endless","seed":42,"enclosed_fill":true,"anchored_blocks":true}
```

只接受布尔值；谜题拒绝 `enclosed_fill` 字段。非法请求不改变当前状态。
`state.enclosed_fill` 表示启动开关。填入块单格使用 `shape:single`，多格连通块使用 `shape:cluster`，`cells` 列出全部格子；不含 `anchored:true`（缺省 false）。
相同版本、种子、开关及操作可重放；开启填充会消耗额外颜色随机数。

## 落点预览

`afterstates` 不消耗或泄露隐藏随机数。若候选需要随机填充，返回
`enclosed_fill_pending:true`，棋盘停在随机颜色确定之前。若固定块的随机位置尚未确定，
也标记填充可能未完成，因为其位置可能改变区域边界。预览不是这时的完整真实落子结果。
真实对局该字段为 false；录制轨迹保存实际结果，并可精确验证回放。

## 验证

覆盖开口/斜角、墙边/底边、多区域、大面积封顶、随机可重复性、单格身份、一次填充限制、
消除结算、默认关闭、独立开关与组合、查询不改变随机状态及录制回放。

本地验证：43 个 C# 规则测试和 43 个 Python 回归测试通过；Godot 与 WebAssembly 构建通过；
网页单独启用填充并实际生成墙边多色口袋，未启用随机固定块。
