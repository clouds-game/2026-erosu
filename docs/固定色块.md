# 固定色块实验

自由模式新增可选的初始障碍，默认关闭；已有谜题不受影响。

## 规则

- 开局随机放置 3 个单格色块，位于底部 6 行，互不重叠，不预先形成三消。
- 每块仅有一种颜色，按当前颜色配置的权重独立抽取；颜色、位置均由对局随机源决定。
- 固定块参与碰撞与支撑，但不受重力影响。上方普通块可以被它支撑，下方空隙保持开放。
- 匹配仍按边相邻的同色方块对象数量计算。每个固定单格计为 1 块，每个普通四格块也计为 1 块；两者可以混合组成三消。
- 固定块只能通过普通三消移除，使用相同计分规则；移除后上方块按原有重力规则下落，可触发连锁。
- 对局进行中不再生成固定块。重新开始重新生成布局；相同种子、颜色配置和开关可重现布局。
- 开启功能会消耗额外随机数，因此开关不同的同种子对局不保证后续方块序列相同。
- 固定块增加轮廓标记，保留原有颜色辅助符号。桌面和网页的固定块模式使用独立最高分记录。

## 启动

桌面：

```sh
./tools/play -- --anchored-blocks
```

该参数直接进入自由模式，并在重新开始自由模式时保留开关。切换到谜题或三消演示不添加随机障碍。

网页：在游戏地址后加 `?anchored_blocks=true`，例如 `http://127.0.0.1:5000/?anchored_blocks=true`。
省略参数或使用 `false` 即关闭。该参数直接进入自由模式，不新增设置面板。

无界面引擎：

```json
{"command":"start","mode":"endless","seed":42,"anchored_blocks":true}
```

`anchored_blocks` 必须为布尔值，省略时为 false。谜题拒绝该字段，避免随机改变已设计关卡。
快照的 `state.anchored_blocks` 描述启动开关；固定方块包含 `anchored:true`，普通方块省略该字段。
读取方块时缺省值为 false。`placements`、`afterstates`、轨迹录制与重放均使用同一套规则。

## 设计边界

本轮是初始障碍实验，不保证随机布局一定可完全清空，也不限制固定块生成稀有色。
稀有色固定块可能长期占用空间；应先观察实际对局再调整数量、分布或颜色约束。
尚未训练或评估 AI 对该机制的适应能力，旧模型未编码固定属性。

## 验证

覆盖固定支撑的顺序无关性、匹配整块计数、移除后重力、300 个种子/颜色配置组合、
默认关闭的随机兼容性、候选落点模拟一致性，以及 JSON 查询与非法请求不改变状态。

本地验证：36 个 C# 规则测试通过；完整 Python 回归通过，新增固定块轨迹回放通过；
Godot 与 WebAssembly 构建通过，并分别检查了实际渲染。
