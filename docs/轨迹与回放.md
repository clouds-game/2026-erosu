# 轨迹与回放

## 训练前后同种子对比

```sh
python3 tools/play.py --headless --prepare-only
python3 -m AI.compare --seed 3000100 --max-pieces 150
```

生成 `build/ai/comparison/` 中的 before/after.jsonl、summary.json 和自包含 index.html。
浏览器打开 HTML 即可播放、暂停、按落块数拖动和调整速度；不需要联网或外部资源。
重复运行会覆盖该输出目录中的同名结果，可用 `--output` 保留不同实验。

Before 为训练开始时的 `BASELINE` 手写权重，After 为指定模型（默认 starter.json），
不是与随机策略比较。两局共用种子及块数限制，检查已出现块的 ID、形状和颜色一致，
并通过实际引擎逐条回放验证。按第几次落块对齐，各自移动和消除帧在该回合内归一化播放，
不是按墙钟或相同 tick 对齐。早结束的一侧停留在终局；无自动重新开局。

种子 3000100、150 块：训练前 109,700 分、消除 140 块、最高 2 连锁；
训练后 112,400 分、消除 135 块、最高 3 连锁。该局分数提高约 2.5%，两局都达到截断上限。
这是单种子演示，不代表整体提升；统计评估参见 AI 训练文档。

## 单局录制与验证

轨迹用于重现 AI 或 JSON 客户端的完整对局。首版支持 CLI 验证与终端逐步显示，
不是 Godot 窗口录像；桌面玩家输入尚未自动接入录制。

```sh
# 录制：stdin 每行输入 JSON 命令；EOF 正常结束。输出文件必须尚不存在。
./tools/play --record build/ai/manual.jsonl
# 重演并逐条验证真实引擎响应
./tools/play --replay build/ai/manual.jsonl
# 终端棋盘，按 Enter 单步推进
./tools/play --replay build/ai/manual.jsonl --step
# 连续显示（棋盘输出到 stderr）
./tools/play --replay build/ai/manual.jsonl --render
```

AI 的 `python3 -m AI.train play --model AI/models/starter.json --trace build/ai/game.jsonl`
现也写入同一版本化格式。直接使用 `python3 -m AI.trajectory replay 文件 --render --delay 0.1`
可设置每个命令的展示间隔；等待只控制播放速度，游戏时间仍由记录的 tick 决定。

## 格式 v1

UTF-8 JSONL，每行一个对象，字段均为 snake_case：

- 首行 `type:header`，含 `format:chroma_trajectory`、`version:1`、协议版本、
  60 Hz tick 频率及实际运行引擎 DLL 的 SHA-256。
- 中间行 `type:step`，从零连续编号的 `index`、原始 `request` 和完整 `response`。
  响应含块 ID、颜色、坐标、消除波、分数和 ticks，可用于离线特征提取。
- 末行 `type:end`，含 `steps` 与全部 step 行按排序键、紧凑 JSON 规范化后的 SHA-256。
  正常退出才写入结束行；没有结束行的中断录制不得通过验证。

支持在同一轨迹内多次 start、暂停、无效命令响应。录制入口要求输入为有效 JSON 对象；
语法错误会终止录制并保留不完整文件。每条记录写完立即刷新。
旧版只有 request/response 的 AI trace 不属于 v1，需重新录制。

回放先检查格式、索引、数量和摘要，再新建引擎并重发全部请求。每一步逐字段比较响应，
包括 RNG 结果、计时、事件、分数和状态；首个差异返回非零退出码并指出步骤与字段路径。
引擎指纹不同会提示，但仍允许实际验证；不承诺跨 .NET 版本、规则版本确定性。
摘要用于检测损坏，不提供签名或防篡改认证。完整文件目前载入内存，不适合无限长录制。

终端数字 0–4 表示静态块颜色，A–E 表示活动块颜色，`.` 为空格。终端显示主要用于
检查操作序列，不表达整块边界；精确块身份保留在 JSON 中。单步要求交互终端。

## 验证

`python3 -m unittest discover -s tools -p 'test_trajectory.py'` 覆盖真实引擎往返、
暂停与重置、错误响应、截断文件、损坏校验、逐字段分歧及异常录制无完成标记。
